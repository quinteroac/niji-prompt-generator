# Midjourney Prompt Generator

A browser extension that generates prompts for Midjourney using the OpenAI API.

## Features

- Automatic generation of prompts for Midjourney.
- Integration with the OpenAI API.
- User interface accessible from the extension's popup.
- Customizable settings through the options page.

## Installation

Follow these steps to install the extension in your browser:

1. Clone the repository:
   ```bash
   git clone https://github.com/username/midjourney-prompt-generator.git
   ```

2. Navigate to the project directory:
   ```bash
   cd midjourney-prompt-generator
   ```

3. Open your browser and go to the extensions page. In Chrome, navigate to `chrome://extensions/`.

4. Enable "Developer mode" in the top right corner.

5. Click "Load unpacked" and select the project folder.

## Usage

1. Click on the extension icon in the browser toolbar.
2. Use the popup interface to generate a new prompt.
3. Configure additional options on the extension's options page.

## Permissions

The extension requires the following permissions:

- `activeTab`: To interact with the active tab.
- `scripting`: To execute scripts on web pages.
- `webRequest`: To intercept and modify web requests.
- `storage`: To store user settings.
